# Roland TR-1000 - single-channel drum kit
# Definition revision 0.1.0 - researched 2026-10-20
# Target HapaxOS 3.22 and TR-1000 system program 1.22.
# Source-reviewed and statically checked; hardware verification pending.
# MIDI chart version 1.20, dated 2026-04-14, pages 1-2:
# https://static.roland.com/assets/media/pdf/TR-1000_MIDIImpleChart_eng02_W.pdf
# Reference manual version 1.20, printed pages 47-49:
# https://static.roland.com/assets/media/pdf/TR-1000_reference_eng03_W.pdf
# Firmware 1.21 and 1.22 report no specification changes:
# https://www.roland.com/us/support/by_product/tr-1000/updates_drivers/1c5d302a-98c4-49b4-beb6-6d788f4b91fe/
# Setup, complete map and caveats: definitions/roland/README.md
#
# Set MIDI Mode to Single Ch. and Pattern Ch. to 10 on the TR-1000.
# Enable RX Note and Rx Edit Data. Check customized Inst Note settings.
# Each Track Ch. uses different channels, notes and slice triggers.
# Track CCs and all drum rows use channel 10. Set the connected output port.
# If changing channel, update Pattern Ch., the track and every drum row.
# CC values are raw 7-bit MIDI data, 0-127; display scaling is not specified.
# CTRL assignments depend on the instrument or effect; keep generic labels.
# No patch defaults, program favorites, CC pairs or NRPNs are configured.
# Row 11 addresses TRIGGER OUT, not an audio voice.
# Rows 12-16 send note 0, unused in the factory Single Ch. trigger map.
# Spare rows are not disabled. Note 0 can trigger a slice in Each Track Ch.
# Keep the internal pattern empty when Hapax sequences the drums.
