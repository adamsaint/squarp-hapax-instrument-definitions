# Erica Synths Perkons HD-01 - single-channel drum kit
# Definition revision 0.1.0 - researched 2026-10-15
# Target HapaxOS 3.22 and Perkons HD-01 firmware 1.2.2.
# Source-reviewed; hardware verification pending.
# Official December 2024 manual, printed pages 31-36:
# https://www.ericasynths.lv/service/file/download/product_id/1167/file_id/521/
# Current firmware and downloads:
# https://www.ericasynths.lv/perkons-hd-01-black-2520/
# Trigger-note numbers corroborated by the community drum-lane example:
# https://squarp.community/t/erica-synths-perkons/15818/2
# Setup, ranges and caveats: definitions/erica-synths/Perkons-HD-01.md
#
# Use SINGLE MIDI CHANNEL mode and the published default CC map.
# MULTI mode reuses CC70-80 on each voice channel; it needs a different setup.
# Check SYSTEM/single-midi-cc.json if the synth's CC map has been customized.
# All CC data is 0-127; switch thresholds are not published in the manual.
# Switches are named but excluded from the initial Assign and automation lanes.
# No explicit parameter defaults, program changes or NRPNs are configured.
# Rows 1-4 are voices 1-4. Hapax retains 16 drum slots.
# Spare rows send note 40, outside the documented C through D-sharp trigger map.
# A spare row is not disabled; confirm silence on your unit before using it.
