# Erica Synths Steampipe - project custom CC map
# Definition revision 0.1.0 - researched 2026-10-15
# Target HapaxOS 3.22 and Steampipe firmware 1.1.
# Source-reviewed; hardware verification pending.
# IMPORTANT: manually configure this custom map on the synth before use.
# These CC numbers are project choices, not Erica's factory assignments.
# Setup and the complete mapping worksheet:
# definitions/erica-synths/Steampipe.md
# Official manual V3, July 2025, PDF sheets 7-9 and 15-16:
# https://www.ericasynths.lv/service/file/download/product_id/1434/file_id/566/
# Current firmware and downloads:
# https://www.ericasynths.lv/steampipe-3153/
#
# 32 continuous panel controls, eight Assign knobs, 32 empty automation lanes.
# Use ordinary single-channel MIDI with MPE off and CC receive enabled.
# Reserve CC20-31, CC40-53 and CC80-85 exclusively for the listed controls.
# Remove conflicting assignments elsewhere in the synth's map and MIDI Device.
# All entries are independent 7-bit CCs with raw values 0-127, not CC pairs.
# Match destinations by panel function; menu wording can differ.
# Reverb Spread is not the firmware 1.1 Voice Spread engine setting.
# No guessed factory map, switch thresholds, LFO addresses or program changes.
# No explicit defaults: the definition does not synchronize with patch values.
