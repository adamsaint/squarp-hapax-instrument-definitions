# The synth receives notes and velocity only; no CC/NRPN sound control.
# Channel 10 is intentional: it is the manufacturer's factory mapping.
# For a learned map, edit each lane's channel and note to match your unit.
# Hi-hat closed note is always two semitones below its learned open note.
# Display order is top to bottom: row 16 Kick through row 7 HH2 Open.
# Hapax keeps 16 slots. Spare rows 1-6 are labeled - and send note 0 on ch 10.
# Note 0 is unused by the factory DRM1 map; it is not a MIDI disable command.
# Load on a fresh track: this revision changes the row layout used by 0.1.x.
