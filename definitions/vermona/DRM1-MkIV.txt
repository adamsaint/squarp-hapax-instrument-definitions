# The synth receives notes and velocity only; no CC/NRPN sound control.
# Channel 10 is intentional: it is the manufacturer's factory mapping.

# Original lane order restored: row 1 Kick through row 10 HH2 Open.
# User testing found that loading starts at the lower rows.
# Hapax keeps 16 slots. Spare rows 11-16 are labeled - and send note 0 on ch 10.
# Note 0 is unused by the factory DRM1 map; it is not a MIDI disable command.
# Load on a fresh track: this revision changes the row layout used by 0.2.0.
