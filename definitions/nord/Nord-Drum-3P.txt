# Nord Drum 3P
# Definition revision 0.1.0 - researched 2026-10-14
# Target HapaxOS 3.22 and Nord Drum 3P OS 1.24.
# Source-reviewed and statically checked; hardware verification pending.
# https://www.nordkeyboards.com/wt/documents/97/Nord%20Drum%203P%20English%20User%20Manual%20v1.x%20Edition%20C.pdf
# MIDI setup pp. 12-14; CC table p. 15.
# Setup, value scaling, and community evidence: definitions/nord/README.md
# CC values are 0-127 MIDI data, not necessarily the panel display values.
# Tone Pitch uses the 14-bit CC31/63 pair; no NRPNs are documented.
# No arbitrary patch defaults are declared.
# Global kit mode: factory notes on global MIDI channel 10.
# CC70 selects which voice receives the shared sound-control CCs.
# Selecting a Hapax drum row does not send a Nord voice-selection command.
# Use the Individual file for simultaneous independent voice automation.
# Voice Select ranges reported by a controller user:
# 1=0-21, 2=22-42, 3=43-63, 4=64-84, 5=85-106, 6=107-127.
# Disable Pad Follow while editing a fixed selected voice.
