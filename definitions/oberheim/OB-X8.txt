# OB-X8: MIDI Param Receive = CC; MIDI Control Enable = On; MPE = Off.
# This replaces the NRPN setup in revisions 0.1.x of OB-X8.txt.
# Existing NRPN automation is not converted; use a fresh track.
# Load on a fresh track and choose the MIDI output port/channel.

# Cutoff and envelope-time endpoint scaling is not established by the manual.
# Do not assume CC127 reaches NRPN175 cutoff or NRPN255 envelope time.
# No explicit parameter defaults or program changes are configured.
